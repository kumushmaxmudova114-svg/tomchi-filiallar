# Tomchi Somsa — Filiallar ilovalari

Bu papkada 3 ta filial uchun **alohida-alohida** buyurtma qabul qilish ilovalari bor. Har biri o'zining belgisi (raqamli rangli nishon bilan) va nomi bilan — lekin barchasi **bir xil Firebase bazasiga** ulangan, ya'ni bu yerda kiritilgan buyurtma darrov dadamning boshqaruv paneliga tushadi.

- `filial1/` — Karvon supermarketi yonida (🟠 to'q sariq belgi)
- `filial2/` — Metromall supermarketi yonida (🟢 yashil belgi)
- `filial3/` — 5u5 dorixona tarafda (🔵 ko'k belgi)

## GitHub'ga qo'shish

Avvalgi `tomchi-somsa` repositoryingizga shu 3 ta papkani ham qo'shing:

1. Repository sahifasida **"Add file" → "Upload files"**
2. `filial1`, `filial2`, `filial3` papkalarini (ichidagi fayllari bilan birga) shu yerga tashlang — GitHub papka tuzilishini saqlab qoladi
3. **"Commit changes"** tugmasini bosing

Bir necha daqiqadan so'ng, har biri o'z havolasida ochiladi:
- `https://SIZNING-USERNAME.github.io/tomchi-somsa/filial1/`
- `https://SIZNING-USERNAME.github.io/tomchi-somsa/filial2/`
- `https://SIZNING-USERNAME.github.io/tomchi-somsa/filial3/`

## Telefonga o'rnatish

Har bir filial xodimi o'ziga tegishli havolani telefonida ochib, "Bosh ekranga qo'shish" qilsin — shunda ekranida o'zining filialiga tegishli nom va rangli belgi bilan alohida ilova chiqadi.

## Eslatma

Bu ilovalar dadamning boshqaruv panelidagi **bir xil** Firestore bazasidan foydalanadi — hech qanday qo'shimcha sozlash shart emas, hammasi avtomatik ulangan.
